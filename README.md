# Festival Runner

3D endless runner. You're a glowing festival-goer dodging crowds, drinks, and security through a psychedelic music festival. Each segment ends in a 90° turn — miss it and you eat the wall.

## Status

**Pivoting to Unity** for native iOS + Android distribution. The original React + React Three Fiber web prototype is preserved at [`_web/`](_web/) for reference (and is still runnable locally with `cd _web && npm install && npm run dev`).

The Unity project will live at the repo root once scaffolded.

## Targets

- iOS App Store
- Google Play Store

## Tech (Unity)

- Unity 6 LTS
- Universal Render Pipeline (URP) — mobile-friendly stylized rendering
- C# scripts in `Assets/Scripts/`
- Procedural / scripted scene assembly walked through in `SETUP.md` (once scaffolded)
